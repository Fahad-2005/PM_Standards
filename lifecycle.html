PMBOK 7 Approach

Core Philosophy

  • Flexible lifecycle selection
  • Supports predictive, iterative, and adaptive
  • Development approach agnostic

Unique Elements

  • Performance domains across lifecycle
  • Hybrid approach enablement
  • Continuous delivery emphasis
📗

PRINCE2 Approach

Core Philosophy

  • Structured stage-based progression
  • Management stages with gates
  • Controlled phase transitions

Unique Elements

  • Pre-project and initiation stages
  • Stage boundary reviews
  • Product-based planning per stage
📙

ISO 21500 Approach

Core Philosophy

  • Process group framework
  • Phase-independent processes
  • Organizational lifecycle integration

Unique Elements

  • High-level process groups
  • Organization-defined phases
  • Programme/portfolio alignment

🔍 Comparative Analysis

🤝 Similarities

  • All recognize distinct project phases
  • Progressive elaboration throughout lifecycle
  • Transition points and decision gates
  • Stakeholder involvement across phases

⚡ Key Differences

  • Structure: PMBOK (flexible), PRINCE2 (stage-based), ISO (process groups)
  • Approach: PMBOK (method agnostic), PRINCE2 (prescriptive stages), ISO (framework)
  • Flexibility: PMBOK (high), PRINCE2 (moderate), ISO (organizational)

🎯 Best Use Cases

  • PMBOK: Projects needing flexible lifecycle approaches
  • PRINCE2: Structured environments with formal stage gates
  • ISO: Organizations with established process frameworks
