PMBOK 7 Approach

Core Philosophy

  • Planning as performance domain
  • Adaptive and progressive planning
  • Value-driven plan development

Unique Elements

  • Flexible planning approaches
  • Just-in-time planning support
  • Rolling wave and iterative planning
📗

PRINCE2 Approach

Core Philosophy

  • Product-based planning methodology
  • Hierarchical plan structure
  • Stage-by-stage detailed planning

Unique Elements

  • Product Breakdown Structure
  • Three-level plan hierarchy
  • Exception-based replanning
📙

ISO 21500 Approach

Core Philosophy

  • Planning process group focus
  • Comprehensive baseline development
  • Organizational planning standards

Unique Elements

  • Subject group planning processes
  • Management system integration
  • Portfolio-level planning alignment

🔍 Comparative Analysis

🤝 Similarities

  • All emphasize comprehensive planning
  • Progressive elaboration recognized
  • Multiple planning levels required
  • Change management and replanning essential

⚡ Key Differences

  • Methodology: PMBOK (adaptive), PRINCE2 (product-based), ISO (process-based)
  • Structure: PMBOK (flexible), PRINCE2 (hierarchical), ISO (integrated)
  • Detail Level: PMBOK (variable), PRINCE2 (stage-specific), ISO (baseline-focused)

🎯 Best Use Cases

  • PMBOK: Projects needing flexible, adaptive planning
  • PRINCE2: Product-focused projects with clear deliverables
  • ISO: Organizations requiring standardized planning processes
