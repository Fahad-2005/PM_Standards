PMBOK 7 Approach

Core Philosophy

  • Integrated change control process
  • Change requests and impact analysis
  • Configuration management system

Unique Elements

  • Change Control Board (CCB)
  • Baseline management approach
  • Version control and traceability
📗

PRINCE2 Approach

Core Philosophy

  • Change theme throughout project
  • Issue and change management
  • Configuration Item Records

Unique Elements

  • Change authority levels
  • Configuration Management Strategy
  • Issue Register maintenance
📙

ISO 21500 Approach

Core Philosophy

  • Control changes process
  • Organizational change procedures
  • Document and information control

Unique Elements

  • Management system integration
  • Portfolio-level change coordination
  • Compliance and audit trails

🔍 Comparative Analysis

🤝 Similarities

  • All require formal change control processes
  • Impact analysis before approval
  • Configuration management essential
  • Change request documentation required

⚡ Key Differences

  • Structure: PMBOK (CCB), PRINCE2 (authority levels), ISO (organizational procedures)
  • Integration: PMBOK (process), PRINCE2 (theme), ISO (subject group)
  • Focus: PMBOK (baseline), PRINCE2 (products), ISO (systems)

🎯 Best Use Cases

  • PMBOK: Complex projects with multiple baselines
  • PRINCE2: Product-driven projects with clear change authorities
  • ISO: Organizations with established change management systems
