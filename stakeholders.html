PMBOK 7 Approach

Core Philosophy

  • Stakeholder performance domain
  • Continuous engagement throughout
  • Proactive relationship management

Unique Elements

  • Stakeholder register and analysis
  • Engagement assessment matrix
  • Communication management plan
📗

PRINCE2 Approach

Core Philosophy

  • Communication Management Strategy
  • Defined roles and responsibilities
  • Information flow structure

Unique Elements

  • Communication management approach
  • Stakeholder analysis as input
  • Reporting through stage gates
📙

ISO 21500 Approach

Core Philosophy

  • Stakeholder subject group
  • Manage stakeholders process
  • Organizational stakeholder context

Unique Elements

  • Identify and manage stakeholders
  • Manage communications process
  • Portfolio stakeholder alignment

🔍 Comparative Analysis

🤝 Similarities

  • All emphasize stakeholder identification
  • Communication planning essential
  • Continuous engagement required
  • Stakeholder analysis and prioritization

⚡ Key Differences

  • Integration: PMBOK (domain), PRINCE2 (strategy), ISO (process group)
  • Documentation: PMBOK (register + plan), PRINCE2 (strategy), ISO (process outputs)
  • Focus: PMBOK (engagement levels), PRINCE2 (roles), ISO (organizational)

🎯 Best Use Cases

  • PMBOK: Complex stakeholder environments
  • PRINCE2: Structured organizations with defined roles
  • ISO: Large enterprises with multiple stakeholder groups
