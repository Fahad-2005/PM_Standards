PRINCE2 Approach

Core Philosophy

  • Closing a Project process
  • Benefits review and handover
  • Post-project review

Unique Elements

  • End Project Report
  • Lessons Log throughout project
  • Follow-on action recommendations
📙

ISO 21500 Approach

Core Philosophy

  • Close project phase process
  • Organizational learning
  • Continual improvement alignment

Unique Elements

  • Collect lessons learned process
  • Knowledge management integration
  • Portfolio-level learning

🔍 Comparative Analysis

🤝 Similarities

  • All require formal project closure
  • Lessons learned capture essential
  • Knowledge transfer to organization
  • Final documentation and archiving

⚡ Key Differences

  • Process: PMBOK (integrated), PRINCE2 (formal process), ISO (process group)
  • Documentation: PMBOK (repository), PRINCE2 (lessons log + report), ISO (knowledge management)
  • Timing: PMBOK (continuous), PRINCE2 (end of project), ISO (phase-based)

🎯 Best Use Cases

  • PMBOK: Organizations building learning repositories
  • PRINCE2: Formal environments requiring structured closure
  • ISO: Enterprises with knowledge management systems
