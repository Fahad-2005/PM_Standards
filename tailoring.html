PMBOK 7 Approach

Core Philosophy

  • Highly flexible principle-based tailoring
  • Context-driven approach selection
  • Value-based adaptation guidance

Unique Elements

  • Performance domain customization
  • Principle preservation focus
  • Project-specific model selection
📗

PRINCE2 Approach

Core Philosophy

  • Structured tailoring guidelines
  • Scale and complexity considerations
  • Theme and process adaptation

Unique Elements

  • Prescribed tailoring boundaries
  • Environment-based customization
  • Controlled flexibility within framework
📙

ISO 21500 Approach

Core Philosophy

  • Organizational context integration
  • High-level guideline adaptation
  • Policy and compliance alignment

Unique Elements

  • Management system harmonization
  • Industry and sector customization
  • Standard-specific implementation

🔍 Comparative Analysis

🤝 Similarities

  • All recognize need for project-specific adaptation
  • Context and environment consideration required
  • Balance between consistency and flexibility
  • Organizational culture alignment emphasized

⚡ Key Differences

  • Flexibility: PMBOK (maximum), PRINCE2 (structured), ISO (organizational)
  • Guidance: PMBOK (principle-based), PRINCE2 (prescriptive), ISO (framework)
  • Scope: PMBOK (project-level), PRINCE2 (methodology), ISO (enterprise)

🎯 Best Use Cases

  • PMBOK: Highly adaptive, diverse project portfolios
  • PRINCE2: Structured environments needing controlled flexibility
  • ISO: Large organizations with compliance requirements
