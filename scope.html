PMBOK 7 Approach

Core Philosophy

  • Scope integrated with planning domain
  • Deliverable and outcome focus
  • Progressive elaboration of scope

Unique Elements

  • Work Breakdown Structure (WBS)
  • Scope baseline development
  • Value-driven scope decisions
📗

PRINCE2 Approach

Core Philosophy

  • Product-based scope definition
  • Product Description documents
  • Clear acceptance criteria

Unique Elements

  • Product Breakdown Structure (PBS)
  • Project Product Description
  • Quality criteria for each product
📙

ISO 21500 Approach

Core Philosophy

  • Scope as planning subject group
  • Requirements and deliverables focus
  • Stakeholder-driven scope

Unique Elements

  • Define scope process
  • Organizational scope standards
  • Portfolio-level scope alignment

🔍 Comparative Analysis

🤝 Similarities

  • Clear scope definition critical for all
  • Deliverables must be well-defined
  • Scope baseline or equivalent required
  • Change control for scope essential

⚡ Key Differences

  • Approach: PMBOK (WBS), PRINCE2 (product-based), ISO (requirements-driven)
  • Documentation: PMBOK (scope statement), PRINCE2 (product descriptions), ISO (process outputs)
  • Focus: PMBOK (work packages), PRINCE2 (products), ISO (organizational alignment)

🎯 Best Use Cases

  • PMBOK: Complex projects with detailed work decomposition needs
  • PRINCE2: Product-focused projects with tangible deliverables
  • ISO: Organizations with standardized scope management processes
